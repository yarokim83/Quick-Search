HPNT 업무자료 검색 — Windows 64비트 독립 실행판

Intel 또는 AMD 64비트 Windows PC용입니다. Google Drive 데스크톱은 별도로 설치되어 있어야 합니다. Python 설치, pip 설치, 별도 프로그램 파일 교체는 필요 없습니다. Python과 검색에 필요한 구성요소가 이 폴더에 포함되어 있습니다.

시작 방법
1. 기존 HPNT 검색앱이 실행 중이면 검은 실행 창을 닫습니다.
2. 이 ZIP 전체를 회사에서 허용한 방법으로 Windows PC에 복사합니다. 보안상 Google Drive 동기화 폴더가 아닌 PC 내부의 보호된 위치에 보관합니다.
3. ZIP을 우클릭하고 '압축 풀기'를 선택합니다. ZIP 안에서 바로 실행하지 마세요.
4. 압축이 풀린 폴더의 HPNT_Start.cmd를 더블 클릭합니다.
5. 첫 실행의 폴더 선택창에서 Google Drive 안의 HPNT_업무 폴더 자체를 선택합니다. 폴더 선택창이 열리지 않으면 실행 창에 폴더의 전체 경로를 입력할 수 있습니다.
6. 브라우저에 http://127.0.0.1:8765/ 가 열립니다. 파일을 100개씩 확인하므로 목록 생성 중에도 검색할 수 있습니다. '자료 처리 현황'에서 확인 수와 오류를 볼 수 있습니다. 자료가 많으면 전체 목록 생성에 시간이 걸립니다.
7. 검색을 마칠 때는 실행 창을 닫습니다. 창이 닫히면 검색앱도 종료됩니다.

동작 범위
- VPN과 맥미니 연결 없이 회사 PC의 Google Drive 폴더를 대상으로 동작합니다.
- 검색 결과의 제목을 두 번 클릭하면 Windows의 기본 프로그램으로 원본 파일을 엽니다. 실행 파일 등 일부 형식은 열기 대상에서 제외됩니다.
- 실행 중 파일명·경로를 약 10분마다 확인합니다. 프로그램이 닫혀 있는 동안과 PC 로그아웃 중에는 동작하지 않습니다. 시작 프로그램 자동 등록은 하지 않습니다.
- 새 파일의 본문은 자동으로 색인하지 않습니다. 엑셀 미리보기는 셀과 지원되는 삽입 이미지를 간략히 보여주며, 20MB를 넘는 문서는 미리보기가 제한됩니다. 원본 서식 및 이미지 배치와 다를 수 있습니다.
- 검색 목록과 선택한 폴더 설정은 이 PC의 %LOCALAPPDATA%\HPNT_Search_Standalone에 저장됩니다. 맥의 검색 목록과 별도로 관리됩니다. 이전 시험판 목록은 자동으로 이전하거나 삭제하지 않습니다.
- 앱은 이 PC에서만 127.0.0.1:8765로 동작합니다. 프로그램에 별도의 사용자 로그인 기능은 없습니다. 검색 목록과 앱 폴더는 업무정보로 보호하세요.
- 이 프로그램과 검색 목록은 업무자료를 포함할 수 있습니다. 허용된 방식으로만 옮기고 공유·동기화하지 마세요. 맥과 Windows가 같은 SQLite 검색 목록 파일을 동시에 공유하면 안 됩니다.

수동으로 보완한 검색 정보 가져오기(선택)
첫 목록 확인이 완료된 후 HPNT_Import_Notes.cmd를 실행하면 138개 대조 대상 중 같은 경로와 실제 내용이 정확하게 일치하는 문서의 검색 정보를 가져옵니다. 온라인 전용 파일은 이 단계에서 다운로드될 수 있습니다. 자료 내용이 다르거나 찾지 못하면 자동 적용하지 않습니다. 맥에서 대조 기준을 확보하지 못한 5개 문서와 이후 변경사항은 자동 이전되지 않습니다.

확인 범위
독립 저장 위치, 검색 목록 생성, 파일명 검색, 엑셀 미리보기와 수동 검색 정보 대조를 Mac의 임시 시험 환경에서 확인했습니다. Windows 64비트용 공식 Python 실행파일과 필요한 라이브러리 파일을 포함하고 구조를 검사했으나 실제 회사 Windows PC에서 실행하거나 Google Drive Windows 동기화를 시험하지 못했습니다. 회사 보안 프로그램이나 Windows 정책이 .cmd 또는 포함된 실행 파일을 차단할 수 있습니다. 문제가 있으면 실행 창의 메시지를 확인하세요.
