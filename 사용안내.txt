HPNT 업무자료 통합 검색 — Windows 64비트 독립 실행판 (v1.4.3)

Intel 또는 AMD 64비트 Windows PC용입니다. Google Drive 데스크톱이 설치되어 있어야 하며, 별도의 Python 설치나 pip 설치가 필요 없는 완전 독립 실행 패키지입니다.

[시작 방법]
- 단일 배포 EXE 사용 시:
  1. HPNT_Search_Windows_v1.4.3.exe 를 더블클릭하면 터미널 창 없이 백그라운드에서 자동 준비되고 바탕화면에 'HPNT 업무검색.exe'를 만든 뒤 바로 실행됩니다.
- ZIP 압축 파일 사용 시:
  1. 기존 검색 서버가 실행 중이면 우측 하단 시스템 트레이 아이콘에서 '검색 서버 종료'를 선택합니다.
  2. ZIP 전체를 PC의 원하는 폴더에 우클릭 → '압축 풀기'로 풀어 주세요. (ZIP 안에서 바로 실행하지 마세요.)
  3. 압축이 풀린 폴더 안의 HPNT_Search.exe 를 더블클릭합니다. (콘솔 실행이 필요할 때는 HPNT_Start.cmd 사용)
- 공통:
  4. 처음 실행 시 폴더 선택창에서 Google Drive 안의 HPNT_업무 폴더를 선택합니다.
  5. 브라우저에 http://127.0.0.1:8765/ 화면이 자동으로 열리며, 실행 중에는 Windows 우측 하단 시스템 트레이(시계 옆 숨겨진 아이콘 영역)에 HPNT 아이콘이 상주합니다.
  6. 트레이 아이콘 더블클릭으로 검색 화면을 다시 열 수 있고, 우클릭 메뉴의 '지금 목록 갱신' / '검색 서버 종료'로 제어할 수 있습니다.

[주요 기능]
1. Everything 스타일 초고속 실시간 검색:
   - 한 글자 입력부터 한글 입력 조합 중에도 즉시 파일명·폴더명·색인 본문이 실시간으로 검색됩니다.
   - 검색 연산자: -제외어 (예: HOIST -복사본), A | B (OR 검색), "정확한 구문", path:폴더, ext:pdf,xlsx
2. 과거 Outlook 보관 메일 통합 검색:
   - 같은 Google Drive 안의 메일보관_백업_2026-10-31(메일검색.html)이 있으면 40,360건 메일과 첨부파일을 업무 파일과 한 번에 같이 검색합니다.
   - 상단 [✉️ 메일 자료만] 칩이나 좌측 [✉️ 메일보관] 폴더로 메일만 따로 찾아볼 수 있습니다.
3. 3-영역 실무 화면 & 즉시 열기:
   - 좌측: 업무 폴더 탐색 / 실시간 결과 분포(폴더·확장자·유형) / ⭐ 즐겨찾기 / 🕒 최근 열람
   - 중앙: 표 보기 ↔ 카드 보기 전환(단축키 v), 경로 폴더 클릭 필터링
   - 우측: 문서 인스펙터 — 원본 열기(더블클릭 또는 Enter), 탐색기 폴더 열기, 경로 복사, 엑셀 시트·PDF 인라인 미리보기

[목록 갱신 & 데이터 보관]
- 실행 중 10분마다 자동 스캔하며, 새 파일을 넣은 직후에는 화면 우측 상단 [지금 목록 갱신] 버튼을 누르면 즉시 반영됩니다.
- 검색 목록과 설정은 %LOCALAPPDATA%\HPNT_Search_Standalone 에 저장됩니다. (업무 원본 자료는 읽기 전용으로만 참조하며 수정하지 않습니다.)
- 수동 보완 검색 정보 138건 가져오기(선택): 초기 목록 확인이 끝난 뒤 HPNT_Import_Notes.cmd를 실행하세요.

[보안 안내]
- 앱은 이 PC 내부(127.0.0.1:8765)에서만 동작하며 외부 전송을 하지 않습니다.
- 앱 폴더와 %LOCALAPPDATA%\HPNT_Search_Standalone 폴더에는 업무 자료 색인이 포함될 수 있으므로 외부 공유나 무단 업로드를 금지합니다.
